# ABC目覚まし

AtCoder ABCのB問題(C問題に切り替え可)を出題し、ACするまで15分おきに鳴り続ける目覚ましPWAです。

公開ページ: https://ruaku1352.github.io/abc-ararm/

## しくみ

- 設定時刻になると、ABCのランダムな回のB問題(またはC問題)を出題してアラームが鳴ります。
- 「止める」で音は止まりますが、15分後にまた鳴ります。このスヌーズは解除できません。
- 出題中の問題を自分がACすると、自動で終了します。ACの判定には [AtCoder Problems](https://kenkoooo.com/atcoder/) の提出データを使います(反映まで数分かかります)。
- アラーム音は手元のMP3ファイルに変更できます。

## 使い方

1. スマホで公開ページを開き、ホーム画面に追加します。
2. AtCoderのユーザー名と起床時刻を設定し、「アラームをセット」を押します。
3. アプリを開いたまま、画面をつけて充電しておきます。アプリを閉じたりスリープすると鳴りません。

## ファイル

- `index.html` アプリ本体
- `manifest.webmanifest` PWAの設定
- `sw.js` オフライン対応と通知のためのService Worker
- `icon-*.png` アイコン
